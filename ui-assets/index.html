Macrocosim reference

Microgrids

  • The Microgrids button in the top bar, or 1, opens a card grid of every registered microgrid: the script's, plus any added via the + New microgrid card or POST /api/microgrids. The last-selected microgrid persists in localStorage; a refresh restores it.
  • The ⇪ Import site… card creates a microgrid from a microgrid API site export: pick components.json and connections.json together (connections optional). Rated power bounds, battery capacity, SoC range and the grid's rated fuse current all carry over into the simulation.
  • Clicking a card drills into that microgrid's Topology + Dispatches sub-tabs. The ← Microgrids button in the header returns to the list.
  • Each microgrid runs its own Microgrid gRPC server on [::1]:<port> (default 8800, 8810, 8820, …). PlatformAssets runs on a single shared port (default 9900).
  • Component ids are globally unique across the enterprise — copying a selection from one microgrid and pasting into another (Ctrl/Cmd+V) re-creates the structure with fresh ids.

Aggregations

  • The Metrics button in the microgrid bar opens live site metrics — power, reactive power / PF, frequency — read from the same frequenz-microgrid client a production control app would use. The Formulas button next to it shows how each of those aggregates is derived from the topology; every #N in a formula is a link back to the canvas.
  • Top-bar pills — graph (✓ / ⚠) summarises validation warnings from frequenz-microgrid-component-graph; loopback is the Microgrid client status; theme and density toggle visual options, and the zone chip shows every time in this browser's zone or in UTC.

Topology canvas

  • Click a node — inspect it (charts + config + knobs in the floating inspector; click empty canvas or Esc to dismiss).
  • Shift+Drag on empty canvas — rubber-band a selection rectangle; nodes inside the box are selected.
  • Shift+Click a node — toggle that node into / out of the current selection (after a rubber-band, or to build one a node at a time).
  • Ctrl/Cmd+hold + drag from one node to another — create an edge between them.
  • Double-click a node — select it together with everything it feeds (its whole subtree). Shift+Double-click adds the subtree to the selection.
  • Right-click — context menu. With a selection: Copy, Cut, Delete. With two or more nodes selected, the menu grows the arrange tools: align as a grid / lanes / radial, align in a row / column, spread, mirror, and spacing. With nothing selected and a non-empty clipboard: Paste. Right-clicking a node not in the current selection resets the selection to that node first.
  • Layout picker (top-right of the canvas) — lanes (default), columns, top-down, radial. Dragging a node by hand keeps your arrangement; picking a layout resets it. The snap toggle makes dragged nodes snap to a grid; hold Alt while dragging to move along one axis only.
  • Ctrl/Cmd+C — copy selection. Ctrl/Cmd+V — paste. Ctrl/Cmd+X — cut. Each paste re-uses the last copy; clipboard captures structure only (types + internal edges), so clones take the type's defaults and the lowest free ids from 5000.
  • Del / Backspace — delete selection. Ctrl/Cmd+A — select all visible. Esc — deselect.
  • Ctrl/Cmd+Z — undo the last canvas edit. Ctrl/Cmd+Shift+Z (or Ctrl/Cmd+Y) — redo. The history lives on the server, one step per structural edit of the microgrid, so it survives page reloads and is shared by every open tab. It is lost on a restart, and a script save clears it for the script's microgrids.
  • The Metrics, Formulas and Weather buttons in the microgrid bar open that microgrid's panels. Formulas opens the formula explorer: pick a metric, hover a part of the formula to highlight its components on the canvas (subtracted parts show red), click a #N to jump to that component. The Engine options card changes how the formula is generated; all options are view-local. Metrics opens the site metrics panel: foldable Power / Reactive power / Frequency cards, each a live chart over the derived aggregate streams, with chips that read out the latest value and toggle their series off the chart.

Inspector + chrome

  • Inspector — one of the panels, alongside the formula explorer, metrics, weather, the log tail, Defaults and the Report; each closes with its × or Esc (newest first). The inspector appears when you click a node (charts + config + knobs), and also closes when you click empty canvas or switch tab.
  • Docking — a panel opens docked the first time: the logs along the bottom, every other panel down the right, and the canvas narrows to make room. A floating panel's ⤓ button offers to dock it into a strip along the bottom or down the right edge of the window, where it becomes a tile and stops covering the canvas; a strip appears only while it holds a tile, and the divider beside it drags to change its size. The tile's ⤒ floats it back to where it was, and the panel opens floating from then on. Several docked panels share a strip: drag the divider between two tiles to trade space, drag a tile's head along the strip to reorder. A docked panel that you close comes back docked. You can also drag a floating panel's grab strip onto the bottom or right edge of the canvas to dock it there, and drag a tile's head out of its strip to float it again.
  • Add component — the + Add button at the top-left of the Topology canvas opens a palette: click a button and a component appears under the lowest free id from 5000, with a color dot matching its node's category colour. hidden meter adds a meter the gRPC topology leaves out (its node draws dashed). Wire it via Ctrl/Cmd+drag.
  • Values — nodes show current power (and reactive power or SoC); the grid node shows the grid frequency, amber from 0.1 Hz away from 50 Hz and red from 0.2 Hz. Edges take the colour of the direction power actually flows (blue import, green export) and thicken with its magnitude. The values pill (top right) toggles the numbers; off, nodes show name and id only. Hovering a node on Topology opens a detail card.
  • Defaults — the values the engine fills into each component type's spec, read-only, in its own panel.
  • Editing — every structural edit changes the microgrid's spec and rebuilds it. A component whose spec did not change, or changed only in its name or modes, keeps its SoC, plugged car, boiler pressure, history and energy; its health, modes and driven knobs go back to the spec, so a mode or health set in the inspector or the Mode: menu lasts until the next structural edit. An edited here chip marks a script's microgrid edited in the UI: saving the script replaces those edits, so export them to keep them. An in memory only chip marks a microgrid made here. Copy as Python and Save as .py in the microgrid bar export it as a Python module.
  • Logs — the Logs button in the top bar opens the server's log tail. Its show dropdown sets a minimum level (lines below it stay hidden) and clear empties the tail.
  • Report — the Report button in the top bar opens the recording of the selected microgrid, or of the lowest-numbered one while none is selected: whether it runs, its totals and peaks, its recent events and the CSV files it wrote. A script records with Microgrid.record().
  • Script chip — in the top bar while the engine runs a script: its state, and on a click the last reload and the script's recent output.
